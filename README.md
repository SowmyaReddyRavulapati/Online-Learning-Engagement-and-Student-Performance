# Online Learning Engagement and Student Performance Analysis

## 1. Project Overview

- Analyzes online learning engagement and student performance using SQL and Power BI.
- Helps understand how student participation affects academic performance.
- Identifies risk levels, dropout patterns, and final results.

## 2. Objectives

- Analyze student engagement in online learning.
- Study academic performance and average scores.
- Examine total clicks and engagement levels.
- Identify high-risk and dropout students.
- Compare performance based on region, gender, and education level.
- Develop an interactive Power BI dashboard.

## 3. Technologies Used

- **SQL:** Used for database creation, data cleaning, and data analysis.
- **Power BI:** Used for dashboards, charts, KPIs, and reports.
- **Power Query:** Used for data cleaning and transformation.

## 4. Dataset

- **Dataset:** `online_education_dataset.csv`
- **Records:** 32,593
- **Fields:** 14
- **Format:** CSV

## 5. Dashboard Features

- KPI cards for important student statistics.
- Performance analysis using charts and graphs.
- Engagement analysis based on student activity.
- Risk and dropout analysis.
- Regional performance analysis.
- Gender and education-level analysis.
- Interactive slicers and filters.

## 6. Project Process

1. Collect and prepare the dataset.
2. Create and analyze the database using SQL.
3. Clean and transform data using Power Query.
4. Create measures and the data model in Power BI.
5. Develop charts, KPIs, and dashboards.
6. Test dashboard performance and usability.
7. Present meaningful insights.

## 7. Conclusion

- Converts student learning data into meaningful insights.
- Helps understand engagement, performance, risk, and dropout patterns.
- Provides an interactive and easy-to-understand Power BI dashboard.

## 8. Future Scope

- Add real-time student activity data.
- Use machine learning for dropout prediction.
- Predict student academic performance.
- Add student-level drill-through analysis.
- Provide automated alerts for at-risk students.
