# Online Learning Engagement and Student Performance Analysis

## Overview

This project analyzes **online learning engagement and student performance** using **SQL and Power BI**.

The project uses student-level online education data to study engagement, academic performance, risk levels, dropout patterns, and final course outcomes. SQL is used for database setup and analysis, while Power BI is used for data preparation, visualization, dashboards, and reporting.

## Objectives

* Analyze student engagement in online learning.
* Study academic performance and average student scores.
* Examine engagement levels and total clicks.
* Analyze student risk levels and dropout patterns.
* Compare student outcomes across regions, gender, and education levels.
* Create an interactive Power BI dashboard.
* Present meaningful insights through charts, KPIs, and filters.

## Technologies Used

* **SQL** – Database setup, data cleaning, querying, and analysis.
* **Power BI** – Data preparation, visualization, dashboard, and report development.
* **Power Query** – Data cleaning and transformation.

## Project Process

1. Collect and prepare the online education dataset.
2. Create the database and analyze the data using SQL.
3. Import and clean the dataset in Power BI.
4. Remove duplicate records and standardize data values.
5. Create calculated measures and prepare the data model.
6. Create KPIs, charts, graphs, and interactive filters.
7. Develop interactive Power BI dashboards and reports.
8. Perform performance testing.
9. Document and present the findings.

## Dataset

The project uses **online_education_dataset.csv**.

* **Records:** 32,593
* **Fields:** 14
* **Format:** CSV
* **Data Size:** Approximately 3.10 MB

The dataset contains information related to student ID, gender, region, education level, study credits, IMD band, total clicks, average score, engagement level, performance level, risk level, pass flag, dropout flag, and final result.
